# Portfólio Alex Monteiro - Tech Purple

Projeto em PHP com visual moderno, tema roxo, vídeo de fundo, animações e seções para:
- Perfil profissional
- Projetos relevantes do GitHub
- Livros e materiais autorais
- Stack técnica
- Contato com LinkedIn e GitHub

## Como rodar no XAMPP

1. Extraia a pasta `portfolio-alex-purple`
2. Copie para `C:\xampp\htdocs\`
3. Inicie o Apache no XAMPP
4. Acesse:

http://localhost/portfolio-alex-purple/

## Arquivos principais

- `index.php`
- `assets/style.css`
- `assets/script.js`
- `assets/hero-tech.mp4`
- `assets/avatar-alex.png`
